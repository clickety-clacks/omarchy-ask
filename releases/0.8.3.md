# Omarchy Ask 0.8.3

- The YOLO / Ask switch now reaches the agent itself, not only Ask's own
  permission prompts. Before, Codex kept its own default "Approve for me"
  mode under YOLO: tools ran sandboxed, and its automatic reviewer could reject
  them without Ask ever showing a request. Now YOLO puts Codex in full access
  and Claude in bypass-permissions mode, and Ask puts both in a mode that asks
  first. This applies when a conversation starts and every time you flip the
  switch mid-conversation.
