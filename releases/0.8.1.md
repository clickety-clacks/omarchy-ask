# Omarchy Ask 0.8.1

No behaviour change from 0.8.0.

- Tests, fixtures and docs no longer name the maintainers' machines, private
  network addresses or home directories; they use placeholder host names and
  documentation addresses.
- The live launch round-trip test now opts in with `ASK_TESTBED=1` instead of
  checking for one machine's host name.
- Bundled agent-window-resolver re-vendored from upstream `main` (same code as
  0.8.0, with the same cleanup in its fixtures).
