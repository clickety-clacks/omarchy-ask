# Omarchy Ask 0.7.0

- Choose a harness, model, and thinking level with Super+comma inside Ask.
  Selections persist across restarts; existing conversations retain their session.
- Follow Omarchy's Default Agent when no Ask override is saved. Use the system
  Codex or Claude installation, never a silently substituted bundled harness.
- Show actionable launch/login errors and offer a new-session recovery button.
  Recovery keeps previous text visible but does not replay it to the new agent.
- Update ACP adapters and use exact model selections, including Fable 5 versus 5.1.
- Fix completion attention through the actual native Qt window. Optional Yoohoo
  receives native urgency; no special hook is needed and focused windows are ignored.
- Leave pinned-window borders, rounding, and clipping to Hyprland. Overlay frames
  retain their desktop theme.

Supported system harnesses: Codex and Claude Code. Other Omarchy defaults show
a selection/recovery message. Model availability still depends on the installed
harness version and account access. No credentials or settings migration is required.

Verification includes 41 live model/effort checks, missing-login tests for both
harnesses, six automated regression tests, and installed-window urgency checks.
See docs/model-verification.md and docs/reviews/2026-09-04-native-attention.md for
scope and limitations. This is not a long-running reliability-soak certification.
