# Omarchy Ask 0.8.0

## Remote agents over Eternal Terminal

- Opening an Agentd Hub agent on another machine can now use Eternal Terminal
  (`et`) as well as mosh and ssh. Over et, apps in the remote tmux follow
  Ghostty's light/dark mode; mosh cannot relay those reports.
- New `agentdHub.transport` in `ask.json`: `"auto"` (default), `"et"`,
  `"mosh"`, `"ssh"` or `"local"`. `auto` uses et when this machine has `et`
  and the host's etserver answers, then mosh, then ssh. Without et set up,
  nothing changes: mosh first, ssh fallback.
- The first open on a host checks whether etserver answers and UDP reaches
  mosh's ports, over the SSH connection Ask already uses to verify the agent,
  and remembers it for a week under
  `~/.local/state/omarchy-ask/transport-capabilities/`. `ask.json` is never
  rewritten with it. A check that times out changes nothing.
- et and mosh fall back to `ssh -tt` in the same window if they cannot start,
  and drop the remembered result when the host is still reachable. A normal
  detach never reconnects. Ask now checks that ssh is installed instead of
  assuming it, and shows which client is missing.
- Ask and Yoohoo now follow one written policy with shared test vectors
  (agent-window-resolver's `docs/transport-policy-v1.md`).
- The bundled resolver is agent-window-resolver 0.2.0 from
  https://github.com/clickety-clacks/agent-window-resolver. Its exact commit
  is recorded in `bridge/agent_window_resolver/VENDORED.json` and checked by
  the test suite; `scripts/sync-resolver.py REF` re-vendors it. It recognises
  et windows, and Ask reports an outdated bundled copy as too old.

To use et, install Eternal Terminal on both machines (Arch/AUR:
`eternalterminal`, not `eternal-terminal`) and run `etserver` on the remote
host. Launchers outside Ask keep their own transport choice.

## Also in this release (unreleased since 0.7.1)

- Agent search, streaming file search with independent local and mounted
  sources, shortcut scope, image paste, and the menu entry.
- One settings window on `Ctrl+,` for agent, Agentd Hub and scroll motion.
- Compositor access isolated in one bridge module; picked windows are
  presented, not only focused. On Scottland, Ask talks to Wayfire IPC
  directly instead of the Hyprland shim.
- Submitted images stay visible beside their prompt in the transcript.
